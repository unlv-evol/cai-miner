GHAgentCI: coding agents in CI workflow histories

Repositories now start coding agents such as Claude Code, Copilot and Codex from GitHub Actions, where they review, triage and change code with the token and secrets the workflow hands them. GHAgentCI holds the complete histories of the workflow files that do this, mined from 196,253 active GitHub repositories, with every agent invocation located at the step that makes it.

What is included

All files are on Zenodo under doi:10.5281/zenodo.24088832, released under CC BY 4.0. Author and committer emails are replaced by a salted hash; names are kept as git records them. Every column is documented in DATASET.md.

Relational schema

Four tables plus the content store. A file's history is identified by (repository, uid): the uid survives renames and content changes.

repositories

  • repository
  • n_commits
  • n_workflow_files
  • n_agentic_files
  • agents
  • first_agentic_date
  • last_agentic_date
  • status
  • + blob accounting

revisions

  • repository
  • uid
  • commit_hash
  • commit_date
  • file_path
  • git_change_type
  • content_sha256
  • triggers
  • permissions
  • agents
  • agentic
  • actor_gated
  • + git metadata

steps

  • repository
  • uid
  • commit_hash
  • agent
  • evidence_kind
  • scope
  • job_id
  • step_index
  • action
  • action_version
  • triggers
  • tasks

ghaw_manifests

  • repository
  • uid
  • commit_hash
  • artifact_kind
  • agent_id
  • compiler_version
  • tools
  • safe_outputs
  • network
  • sandboxed
  • + counts

content/<sha256>.yml

  • content_sha256
  • the workflow file as committed
repositories 1 — n revisions on repository; a history is (repository, uid).
revisions 1 — n steps and 1 — 1 ghaw_manifests on (repository, uid, commit_hash).
revisions n — 1 content on content_sha256; frame joins repositories on name = repository.

Mine your own repositories with cai-miner

The dataset was built with cai-miner, an open-source tool that parses every revision of every workflow file and classifies agent evidence into strong and weak tiers. It works on local clones and needs no API token.

Install and run

pip install cai-miner

git clone --filter=blob:limit=64k --no-checkout \
    https://github.com/OWNER/NAME.git clone
cai-miner clone -o out/

Load the dataset with pandas

import pandas as pd
base = "https://zenodo.org/records/24088832/files"
steps = pd.read_csv(f"{base}/steps.csv.gz?download=1")
steps.groupby("agent").repository.nunique()
